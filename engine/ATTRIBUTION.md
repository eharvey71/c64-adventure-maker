# Engine attribution

The files in this folder are from **StoryTllrC64** by Marco Giorgini,
used under the MIT license:

    https://github.com/MGProduction/StoryTllrC64

- `storytllr64.prg` — the C64 player program (from the repo's `bin/`)
- `stdlib.hjt`      — the script standard library (from `samples/accuse/`)
- `font.png`        — the game font (from `samples/shared/png/`)

They are redistributed unmodified so that games built with this kit are
self-contained. The `script_compiler` is NOT bundled — build it from the
StoryTllrC64 source with the patches in `../tools/fix_storytllr_compiler.sh`.
