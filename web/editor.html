    Objects

      Pick an object on the left, or add one.

      Object details

      TAKEABLE: can be picked up. HIDDEN: not listed in the room. FIXED: stays put. Separate several with commas.

      Vocabulary

      One word per line: WORD=SYNONYM,SYNONYM — for example EXAMINE=X,INSPECT,SEARCH

      Custom messages

      One per line: KEYNAME=Your message text. Use one in a response with the action MSG KEYNAME. They work in both targets. The win message is in the settings above.

      Responses

      One per line: COMMAND:CONDITION:MESSAGE:ACTION — for example TAKE KEY:AT 5:YOU PICK UP THE KEY.:SCORE 10

      The left column says whether each line runs in both targets or only in the graphical build.
